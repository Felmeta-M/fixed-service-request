# Documentation

This folder contains the official training and reference documentation for the Fixed Service Request system.

## Student training

**[Student Training Manual](STUDENT_TRAINING_MANUAL.md)** — Chapter-by-chapter training for software engineering students. It covers:

- System architecture (host Nginx, Docker, database, Redis)
- Development environment setup
- Payment gateway integration (Telebirr): concepts, flow, and security
- **Deployment:** staging (Docker Compose, HTTPS, host Nginx) and production (SSL, reverse proxy)
- Database and operations basics
- Summary and quick reference

Use this manual for coursework, labs, and deployment exercises. Prerequisites: PHP/Laravel basics, Docker, REST APIs, basic Linux administration.
